## 外部接入的明确限制

- 飞书默认关闭，没有在本次测试中访问公司日历或发送真实提醒。
- 当前使用管理员批准应用取得的 user_access_token，需手动更新过期凭据；未内置 OAuth 服务或应用密钥。
- 自动提醒采用飞书作为日历提供方。是否可用取决于公司权限，以及后续真实通知验证。
- Nutstore Sync 继续负责 Markdown 文件同步，插件不提供自己的同步服务器。需要在两端确认完整数据目录被同步。
- 最低声明 Obsidian 版本为 1.5.0；本次真实验证版本为 1.13.7。密钥存储功能在具备该 API 的版本显示，否则仅使用会话凭据。
- 没有把“请求成功”认定为“手机通知已送达”。后续外部验收必须验证锁屏、应用退出、凭据过期和真实双端修改。
